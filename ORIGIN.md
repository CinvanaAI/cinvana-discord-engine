# Origin and public curation

This repository is a reviewed source snapshot of the CinvanaAI Discord Engine.
The source package, tests, configuration template, and project metadata were
copied; the live `Runtime/` tree and bytecode caches were not.

Publication review blanked the machine-specific Conversation Engine path and
added provenance, security, and license-status documentation. The implementation
and existing tests otherwise remain the source project's own.

No Discord login, guild lookup, reconciliation, or publication call was made
while assembling this snapshot.
